# Security Policy

## Supported Versions

Only the latest version of this extension is supported for security updates.

## Reporting a Vulnerability

If you discover a vulnerability, please report it privately before opening a public issue.

- Contact: `oldfarmer96@gmail.com`
- Include:
  - Affected version
  - Steps to reproduce
  - Potential impact
  - Suggested remediation (if available)

We will acknowledge receipt as soon as possible and work on a fix.
